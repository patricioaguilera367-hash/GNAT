## Domain constraints

S/E is substation; transformer CD of S/E differs from pole COD. Do not invent CD expansion. DC/DF/DBC labels and DF breadcrumb `F514139 -> F66023 -> F514139 [F66023]` are bounded UI evidence, not physical hosting/formal classes/field truth/electrical connectivity.

Raster WMTS PNG MT/BT/infrastructure is visualization. Vector selection and object geometry do not imply global inventory. Coordinates, crossings, shared codes and line labels never authorize inferred electrical edges.

## Blocked scope

Owner-approved independent auth, read fields, cache/retention/rate rights, negative/error/paging/partial behavior and backend type semantics remain unresolved. Session/port availability is not permission. Area inventory needs an explicitly authorized bounded read service and area, not a sweep/load probe.

Electrical sector/isolation needs node/terminal/edge relations, compatible phase/voltage, circuit semantics, time-valid states, event/record timestamps, freshness/quality/reliability, coverage and independent authorization. Unknown state is not closed/connected. No maneuver/opening instructions or operational widget execution belong here.
