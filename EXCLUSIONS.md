## Publication boundary

**Private handoff is not public-release clearance.** Research contains real asset IDs/codes/geolocation facts. Fixture filename `contracts.observed.anonymized.json` does not mean whole package anonymized. No secret values intentionally included; conservative patterns are defense in depth, not comprehensive security/rights audit.

Before public GitHub or AI-provider upload, obtain permission covering destination/data/operation/account; review identifiers/coordinates/rights. A later public derivative must be separately reviewed with referentially consistent anonymization and evidence labels. Never silently modify preservation snapshot. No license/rights invented.

Original ignore policies inert; new policy protects runtime/private caches without hiding V6/V4. Never blind `git add .` in original workspace.
